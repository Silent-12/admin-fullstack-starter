# 编码与注释

> 作用域：`web/`（源码路径相对 `web/`）。规则入口：[web/AGENTS.md](../../AGENTS.md)。

- 新增、修改或重构的公共函数、业务函数、事件处理函数、数据加载函数及其他具有明确业务语义的方法，必须编写或更新标准 JSDoc（`/** */`），优先包含 `@description`、`@param`、`@return` 并简要标注类型与业务说明；无参数或无返回值时省略对应标签。
- Vue `<script setup>` 中的函数同样适用上一条。
- 多行 JSDoc 的标题行、`@description` 行与单行 `/** 说明 */` 行末均不加句号。
- Vue `<script setup>` 中 `ref`、`reactive` 等响应式状态声明必须按语义添加分组或用途注释（如「组件引用」「状态数据」「表单数据」「分页参数」）。
- `<script setup>` 中对外暴露方法、事件处理函数、数据加载函数及其他具有明确业务语义的箭头函数必须补充标准 JSDoc，写法与同目录已有文件保持一致。
- 函数入口或逻辑开始处必须对非法状态、异常输入与不满足条件立即返回或抛错；禁止用 `if/else` 嵌套处理主流程。
- 修改或新增代码时禁止无故删除仍然有效的注释；注释失效、与实现不一致或产生误导时必须同步更新或删除。
- 无用字段、变量、引入与组件必须立即删除，禁止保留兼容代码。
- 文件编码要求：见 [根级工程约定](../../../AGENTS.md#根级工程约定)。
- 类型声明与字段注释：见 [类型定义](typescript.md)。
